# Muslim (مسلم)

A single app that combines the full Mushaf with audio recitation, tafsir for every ayah, short
videos telling the story of each surah, and video series about the prophets. Everything is linked:
from an ayah to its story video, and from a video back to its ayahs.

- Product concept: [docs/concept.md](docs/concept.md)
- Project rules (constitution): `.specify/memory/constitution.md`
- Specs, plans and task lists: `specs/`

This project is developed spec-first with [Spec Kit](https://github.com/github/spec-kit) and uses
[Impeccable](https://github.com/pbakaus/impeccable) for design quality.
